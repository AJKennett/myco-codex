# Glossary

This glossary defines key terms, concepts, and abbreviations used in the RTS game and the Codex. Use it to quickly look up unfamiliar terminology.

- **Codex** – A centralized collection of lore, rules, and reference material about the game world. In this project, the codex is built using MkDocs and published via GitHub Pages.
- **Micro creativity** – A practice of producing small, consistent creative outputs—such as one concept, unit, or storyline detail per day—to gradually build a rich universe.
- **Faction** – A major political or ideological group within the game. The main factions are the **[Last Bastion](factions/last-bastion.md)**, the **[Machine](factions/machine.md)**, and **[The Verdant](factions/verdant.md)**.
- **Units** – Individual combatants, vehicles, or creatures controlled by a faction. See the **[Units Overview](units/index.md)** for descriptions of common unit types.
- **Timeline** – A chronological record of significant events. The **[timeline page](timeline/index.md)** tracks both in‑universe lore and real‑world development of the Codex.
- **MkDocs** – A static site generator that turns Markdown files into a website. It powers this codex. Learn more at [mkdocs.org](https://www.mkdocs.org/).
- **GitHub Pages** – A hosting service that publishes static sites directly from a GitHub repository. This codex is deployed via GitHub Pages.
- **Last Bastion** – The human survivor faction that builds fortified cities and relies on defensive technologies. See the faction page for lore and leaders.
- **Machine** – The faction of autonomous AI, drones, and robots seeking to automate and assimilate the world. See the faction page for details.
- **The Verdant** – A faction of sentient fungal and plant life striving to restore balance through organic growth. See the faction page for more.
- **Guardian Tank** – A heavily armored vehicle used by the Last Bastion, combining mobile firepower with sturdy defenses. Listed on the units page.
- **Siege Walker** – A formidable mechanical war machine fielded by the Machine faction. Designed to bombard fortifications from afar.
- **Sporecaster** – A Verdant support unit that spreads spores to heal allies and hinder enemies. See the units page for abilities.

Feel free to expand this glossary with additional terms as the game's universe grows.
